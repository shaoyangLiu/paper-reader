# 📖 Paper Reader — 本地论文阅读器

一个**本地运行的论文阅读器**，配合 [WorkBuddy](https://www.workbuddy.ai) 生成的中文翻译 HTML 使用。
读论文时先看中文翻译，再对照原文 PDF，并能在翻译 / 原文上做高亮笔记、把截图浮在屏幕上左右对照。

> 零依赖、零构建：原生 HTML/CSS/JS 前端 + Python 标准库 `http.server` 本地服务器 + 内置 PDF.js。

---

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| **双栏对照** | 左 = 中文翻译（iframe 载入），右 = PDF 原文（PDF.js 渲染）。中间分隔条可拖动调宽度（双向都可拖）。 |
| **视图切换** | 顶栏一键切换：`双栏` / `翻译（全屏）` / `原文（全屏）`。 |
| **标注零侵入** | 选中文字 → 色块高亮 + 笔记。所有标注存成独立的 `<翻译名>.anno.json`，**不改动原 HTML / PDF**；用普通浏览器直接打开翻译 HTML 看不到任何标注。下次打开自动载入。 |
| **PDF 原文标注** | 开启 PDF.js 文本层，原文可直接选词高亮 / 做笔记，按页存矩形高亮覆盖层。与翻译标注共用同一 `.anno.json`（`source` 字段区分）。 |
| **笔记抽屉** | 📝 按钮列出全部笔记，按 `原文 P{n}` / `翻译` 标签分类，点击跳转、可删除。 |
| **区域截图悬浮** | 📸 按钮 → 在阅读区**拖拽框选任意区域** → 浮窗。浮窗可拖动、缩放、调透明度、💾 下载、关闭。方便滚中文 / 滚原文对照看。 |
| **字体缩放** | 顶栏 `Aa` 滑块（100%–250%），翻译与原文同步放大。 |
| **滚动同步** | 🔗 双栏时开启，左右按阅读进度比例联动滚动（非逐句对齐）。 |

## 🚀 快速开始

### 1. 放论文
每篇论文一个**子文件夹**，放入 `Literature` 目录（路径见下）：
```
<Literature>/
└── <论文名>/
    ├── <原文>.pdf                  # 原始 PDF
    └── 论文翻译_<中文名>.html        # WorkBuddy 生成的翻译页
```
标注会自动生成 `<翻译名>.anno.json` 在同一子文件夹（无需手动创建）。

### 2. 启动
```text
双击  start-reader.bat
```
自动起服务器并打开浏览器到 **http://localhost:8731/** 。
左侧论文库点一篇即可载入翻译 + PDF。

## 🧰 运行与维护

| 场景 | 操作 |
|---|---|
| 首次 / 日常启动 | 双击 `start-reader.bat`（起服务器 + 开浏览器） |
| **网页打不开** | 双击 `reset-reader.bat`（清端口旧进程 + 重启） |
| 停止服务 | 关闭弹出的 "PaperReader-Server" 黑窗口 |
| 改前端（html/js/css） | 改完浏览器**硬刷新 `Ctrl+Shift+R`** 即生效 |
| 改 `server.py` | 需重启 bat |
| 加新论文 | 直接放进 Literature 对应子文件夹，刷新页面即出现 |

> ⚠️ 服务器**只在运行时**可访问。重启电脑或关掉黑窗口后，需重新双击 bat。

## 📂 文件结构

```
paper-reader/
├── server.py            # 本地服务器（标准库 http.server）
│                         #   /api/papers 列论文 | /api/paper 读 HTML/PDF | /api/annotations 存取标注
├── reader.html          # 阅读器主页面（工具栏 + 双栏 + 浮层）
├── app.js               # 前端逻辑（vanilla JS）
├── styles.css           # 暗色主题样式
├── vendor/
│   ├── pdf.min.js           # PDF.js 3.11.174（内置，离线可用）
│   ├── pdf.worker.min.js    # PDF.js worker
│   └── html2canvas.min.js   # html2canvas 1.4.1（区域截图）
├── start-reader.bat     # 一键启动
├── reset-reader.bat     # 一键修复（清端口旧进程 + 重启）
├── README.md            # 本文件
└── handover.md          # 开发交接文档（完整修改历程）

# 论文与标注（程序不修改、不搬动）：
C:\Users\z3450390\OneDrive - UNSW\Desktop\OneDrive Sync\Literature\
└── <论文名>/  →  <原文>.pdf | 论文翻译_<中文名>.html | 论文翻译_<中文名>.anno.json
```

**关键配置常量（`server.py` 顶部）**
- `LIT_ROOT` — 论文文件夹路径（默认指向上述 Literature 目录；改成你的实际路径即可）
- `PORT` — 服务端口（默认 `8731`）

> 论文 / 标注路径与程序路径**完全分离**：改论文只动 Literature 文件夹，改代码只动本仓库。

---

## ⚙️ 自定义

- **换论文文件夹**：编辑 `server.py` 顶部的 `LIT_ROOT`。
- **换端口**：编辑 `server.py` 顶部的 `PORT`，并同步修改两个 `.bat` 里的 URL。

---

## 📌 已知限制

- ⚠️ **框选翻译区域截图为空**：`html2canvas` 不渲染 `<iframe>` 内部内容。框选 PDF 原文（canvas）正常；框选翻译栏会得到空白（待补：对 iframe 内文档单独截图）。
- ⚠️ **PDF 标注依赖文本层**：扫描版 / 图片型 PDF 无文本层，无法选词高亮（只能截图标注重）。
- ⚠️ **滚动同步非逐句**：按阅读进度比例对齐，非逐句对应。
- ⚠️ **字体放大后截 PDF**：`zoom` 放大截图可能因缩放略有偏差（不影响阅读）。

## 🛠️ 技术栈

- **前端**：原生 HTML / CSS / JavaScript（无框架、无打包）
- **后端**：Python 3 标准库 `http.server`（无第三方依赖）
- **PDF 渲染**：PDF.js 3.11.174（内置）
- **截图**：html2canvas 1.4.1（内置）

为什么用本地服务器而不是双击 HTML？`file://` 协议下无法读取同文件夹 PDF、无法 `fetch` 保存标注；且截图悬浮需要 `localhost` / `https` 安全上下文。用 `localhost:8731` 一次性解决读文件 + 存标注 + 截图三件事。
